NeuroQuizz 🧠⚡

NeuroQuizz Pro es una plataforma profesional de evaluación interactiva diseñada con IA adaptativa y telemetría cognitiva en tiempo real.

🚀 Características Principales:
Cuestionarios Dinámicos: Mide el conocimiento en áreas como matemáticas, cultura, historia y razonamiento lógico.
Dificultad Adaptativa: El sistema ajusta el nivel de exigencia (Fácil, Normal, Difícil) según el rendimiento del usuario.
Comodines de Apoyo: Incluye opción 50/50, estadísticas de simulación del público y un asistente virtual (*NeuroAI Tutor*) con explicaciones paso a paso.
Telemetría y Estadísticas: Gráficos interactivos de rendimiento integrados con Chart.js y exportación de historiales.Soporte, Multiidioma e Interfaz intercambiable dinámicamente entre español e inglés.

🛠️ Tecnologías Utilizadas:
HTML5 Semantic
CSS3 (Variables personalizadas y diseño adaptativo *Ethereal Glass*)
JavaScript (ES6+) (Motor de juego y gestión de estados)
Chart.js (Visualización de datos y curvas de aprendizaje)
Phosphor Icons (Sistema iconográfico)

⚙️ Instrucciones de Ejecución:
Al tratarse de una aplicación web basada en tecnologías nativas y CDNs, no requiere instalación compleja:
1. Clona o descarga este repositorio
2. Abre la carpeta del proyecto y haz doble clic en el archivo `index.html` para iniciarlo directamente en cualquier navegador web moderno
