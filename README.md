# NeuroQuizz
NeuroQuizz Pro es una plataforma web interactiva de evaluación con IA adaptativa y telemetría cognitiva. Mide el conocimiento mediante cuestionarios dinámicos en matemáticas, cultura, historia y lógica. Cuenta con dificultad automatizada, comodines de apoyo, gráficos de rendimiento con Chart.js y soporte multiidioma.
